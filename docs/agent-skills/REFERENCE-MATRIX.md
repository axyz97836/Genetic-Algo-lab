## 2. Core Conflict Rules & Engineering Safeguards

1. **Precedence:** The GA Lab Product Specification (`docs/SPEC.md`) is the sole authoritative source of truth. Any visual pattern, component design, or interaction behavior from Kokonut UI, Bklit UI, ThreeUI, Motion, Anime.js, or Manus that conflicts with `docs/SPEC.md` is rejected.
2. **No Bundling / Transpilation:** No Babel, Webpack, Vite, Rollup, PostCSS, or Tailwind CLI. All source code is authored in standard browser-native ES Modules (`import`/`export`), native Canvas 2D Context, inline SVG, and native CSS.
3. **No External CDN Scripts:** No `<script src="https://cdn...">` tags for animation or charting libraries. Fonts are restricted to Google Fonts (Inter + JetBrains Mono) with system fallbacks.
4. **Complete Traceability:** Every visualization pixel and table cell in GA Lab maps directly to an immutable engine `StepRecord`. No visual element may display fabricated or approximated data.
